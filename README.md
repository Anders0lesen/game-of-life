# Jonas' Game of Life

A mobile-first playground for Conway's Game of Life and other Life-like cellular automata.

## Features

- Finger/mouse drawing
- Play, pause and single-step
- Randomize and clear
- Adjustable simulation speed and cell size
- Conway's Life (B3/S23)
- HighLife, Seeds, Day & Night, Life Without Death, Maze
- Custom B/S rules
- Generation and population counters

The application is deliberately dependency-free: one `index.html` containing the UI and simulation.

## GitHub Pages
